# 元数据卡 · 号外（extra）

> 推送前先读这张卡。标题/摘要/导语不写在正文 HTML 里，是言序 create_article 的独立字段。

## 硬约束
- title：≤30 字（言序硬校验，超了创建失败）
- abstract：≤100 字（同上）
- intro：无字数限制，建议 2-4 句
- 账号：Miller（account_id 4020261023901417208318895104）
- 主题 theme_id：blackgold

## 标题模板（事件 + 钩子，热点快评调性）
1. `{事件}：{一句钩子结论}` —— 例：`XX 翻车：一句道歉为什么没人买账`
2. `号外｜{事件}，{争议点}到底怎么回事`
3. `{数字}亿/{数字}人，{事件}背后的{一个追问}`

## 摘要模板（2 个句式，每个 60-90 字）
1. 「{时间}，{事件}冲上热搜。争议不在{表面问题}，而在{真正分歧}。本文不站队，只把事实摆一边、观点摆一边，再给你一张 {N} 条的后续观察清单。」—— 填入示例约 88 字
2. 「一件{事件}，两种声音：支持方说{观点A}，质疑方问{观点B}。我们拆开事实与判断，钉子话只有一句：{钉子话}。」—— 填入示例约 70 字

## 导语模板（报纸腔、短句、信息密度拉满）
- 「{事件}今天刷屏了。表面看是{表象}，真正的问题是{钩子}。三分钟讲清，不站队。」—— 两三句点明「发生了什么 + 为什么值得聊」，不铺垫。
- 编辑部观点卡必须有一句可引用的钉子话；导语先把钩子抛出来，正文再逐条拆事。

## 写作纪律
1. 事实与观点分离；每段只做一件事：陈述 / 举例 / 下判断。
2. 编辑部观点必须有一句可引用的钉子话；不站队，只拆事。
3. 号外红 `#c9342b` 仅用于观点徽章、关键事实/态度词、引语竖线，全文红色 ≤5 处。
4. 立场对照卡写清支持方▸ / 质疑方▸；WATCHLIST 写清判断标准（本风格灵魂组件）。
5. 标题一句到位不绕弯，导语信息密度拉满无铺垫。
6. 结构顺序：报头 → 导语 → 快评一/二/三 → 引语卡/观点卡/对照卡 → WATCHLIST → 互动 → 报尾 + 口径说明。
