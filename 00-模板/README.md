三种公众号阅读风格的完整模板基线。命名规则：`style-风格.html`（正文模板）+ `cover-风格.html`（封面模板）。

## 风格 A · 锌白（zinc）—— 科技 / 数据 / 清单

| 文件 | 说明 |
|---|---|
| `style-锌白.html` | 正文基线（源：2026.10.22 GitHub涨星TOP10）。全内联样式，zinc 黑白灰单色，黑底头部卡→中文序号章节→要点卡→数据卡→白底条目卡→等宽附录 |
| `cover-锌白.html` | 封面模板（zinc 双规格，浅色为主交付）。网格背景+光晕、tag 药丸、右侧终端卡 |

## 使用约定

1. **创作前先读** `../.workbuddy/style-guide.md` 的对应风格章节，再读本文体模板
2. 正文模板是结构基线：结构、配色、字号、写作纪律照搬；文案内容全部替换
3. 封面与正文必须同风格；每篇出 2.3 比例 + 方版 1x1 两种规格
4. 插图风格跟随正文：锌白→单色几何 / 羊皮卷→做旧厚涂 / 号外→纪实插画（低饱和+红色点睛）；魔兽题材例外，用魔兽官方美术风
