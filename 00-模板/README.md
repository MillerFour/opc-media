# 00-模板 · 风格模板库

四种公众号阅读风格的完整模板基线。命名规则：`style-风格.html`（正文模板）+ `cover-风格.html`（封面模板）。风格名即中文名，聊起来直接说。

## 风格 A · 锌白（zinc）—— 科技 / 数据 / 清单

| 文件 | 说明 |
|---|---|
| `style-锌白.html` | 正文基线（源：2026.10.22 GitHub涨星TOP10）。全内联样式，zinc 黑白灰单色，黑底头部卡→中文序号章节→要点卡→数据卡→白底条目卡→等宽附录 |
| `cover-锌白.html` | 封面模板（zinc 双规格，浅色为主交付）。网格背景+光晕、tag 药丸、右侧终端卡 |

| 文件 | 说明 |
|---|---|

| 文件 | 说明 |
|---|---|
| `style-Nvidia.html` | 正文模板（纯模板含注释）。深绿黑头部卡 → `// 01 CONFIRMED` 事实卡 → 深底数据卡 → `// 02 CLAIMS` 诉求卡 → `// 03 TWO SIDES` 口径对照 → WATCHLIST 深卡 → 口径说明 → 快讯完报尾 |

适用：科技公司快讯、财报、产品发布、人事变动、算力/芯片题材。配色：深绿黑 `#0d1509` + 品牌绿 `#76b900`（浅底正文强调改 `#4c7a00`）+ 亮绿 `#a6e22e` 仅深卡数字 + GPU die 点阵。写作纪律：事实与主张分离、单方主张标出处、敏感指控不转述、不站队、不构成投资建议。言序主题用 `terminal`。

## 使用约定

1. **创作前先读** `../.workbuddy/style-guide.md` 的对应风格章节，再读本文体模板
2. 正文模板是结构基线：结构、配色、字号、写作纪律照搬；文案内容全部替换
3. 封面与正文必须同风格；每篇出 2.3 比例 + 方版 1x1 两种规格
4. 插图风格跟随正文：锌白→单色几何 / 羊皮卷→做旧厚涂 / 号外→纪实插画（低饱和+红色点睛）；魔兽题材例外，用魔兽官方美术风
