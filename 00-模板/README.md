# 00-模板 · 风格模板库

公众号文章的**物料基线库**。每套风格一个文件夹，固定四件套 + 可选生成器。新增风格照此办理。

## 公众号文章的四项物料

| # | 物料 | 文件 | 说明 |
|---|---|---|---|
| 1 | 封面图 ×2 | `封面.html` + `gen_封面.py` | 横版 2.3:1（900×383）+ 方版 1:1（900×900），PNG 交付 |
| 2 | 正文内容风格 | `正文.html` | 公众号适配版，全内联样式，复制范围注释包住 |
| 3 | 插图及风格 | `插图.html` | 1200×780 自绘信息图，截图后压 JPG |
| 4 | 标题 / 摘要 / 导语 | `元数据.md` | 言序推送的独立字段，不在正文 HTML 里；含字数硬约束与主题映射 |

**约束（不是物料）**：封面 / 正文 / 插图必须同一套视觉语言；口径说明归在正文内。

## 每套文件夹的结构

```
00-模板/{风格名}/
├── 正文.html          # 必填 · 纯模板（占位文案，无真实文章数据）
├── 封面.html          # 必填 · 双画板基线（2.3 + 1:1）
├── gen_封面.py        # 选填 · 参数化生成器（统一吃 cfg.json 文件路径）
├── 插图.html          # 必填 · 1200×780 自绘信息图，主容器 id="fig"
└── 元数据.md          # 必填 · 标题/摘要/导语模板 + 主题映射 + 写作纪律
```

风格卡在 `../00-系统/styles/{风格名}.md`，写作时只读风格卡 + 对应正文骨架，不全量读 style-guide。

## 写作纪律（跨风格通用）

1. 创作前先读 `../.workbuddy/style-guide.md` 的对应风格章节 + `../00-系统/styles/{风格}.md`
2. 正文模板是结构基线：照搬结构、配色、字号、写作纪律，文案全部替换
3. **每个 section 显式写 `text-align:left`**，只有结尾居中例外——公众号排版要求
4. 页面顶部 `<style>` 块只用于本地预览，粘贴到公众号会被丢弃，正文样式必须内联
5. 封面与正文必须同风格；每篇出 2.3 + 1:1 双规格
6. 插图风格跟随正文；**禁用 AI 生图**（合规水印不可去除），用 HTML 自绘
7. 推送前读该风格的 `元数据.md`，title ≤30 字、abstract ≤100 字是硬校验

## 封面截图流程（复用）

```bash
# 1. 生成器出 HTML（或直接改 封面.html）
python 00-模板/{风格}/gen_封面.py cfg.json

# 2. 本地静态服务 + playwright-cli 按画板 id 截图
python -m http.server 8321 --bind 127.0.0.1 --directory .tmp-shots
playwright-cli -s=xx open "http://127.0.0.1:8321/cover.html"
playwright-cli -s=xx screenshot "#paper"   # 2.3
playwright-cli -s=xx screenshot "#sq"      # 1:1

# 3. 插图压 JPG
ffmpeg -i fig.png -vf "scale=1200:-1" -q:v 3 插图_1_xxx.jpg
```

踩坑：`playwright-cli` 同一 session 内 `goto` 会崩，每页用独立 session；截图前先 `taskkill //F //IM msedge.exe //T` 清残留进程。

## 新增风格的标准流程

1. 在 `00-模板/` 下建新文件夹，名字就是风格名（中文或英文名均可）
2. 按上面五件套建齐：`正文.html` / `封面.html` / `gen_封面.py`（可选）/ `插图.html` / `元数据.md`
3. `正文.html` 顶部写风格注释块；纯占位文案，不能有真实文章数据；外层容器与所有 section 显式 `text-align:left`
4. `插图.html` 主容器固定 `id="fig"`、画布 1200×780、零外部图片
5. `元数据.md` 按七段结构写全：硬约束 / 标题模板 / 摘要模板 / 导语模板 / 主题映射 / 写作纪律 / 推送检查清单
6. 在 `../00-系统/styles/` 建对应风格卡（yaml 结构对齐已有五张）
7. 更新本 README 的风格表、`.workbuddy/style-guide.md` 注册表、`../.workbuddy/memory/MEMORY.md` 注册表
8. 交付前用浏览器打开三个 HTML 各截一张图验一遍，确认无溢出 / 无重叠
