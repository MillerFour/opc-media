Paperclip：把 AI Agent 管成一家公司
来源：github.com/paperclipai/paperclip（2026-10-23 实查）· 它不造 Agent，也不做框架——它给 Agent 一家公司：组织架构、目标对齐、预算治理、任务分配，一次配齐。
一、核心要点
01 · Agent 是员工，Paperclip 是公司
官方 README 的定位一句话说透："If OpenClaw is an employee, Paperclip is the company."——它不构建 Agent、不是 Agent 框架，而是承载所有 Agent 工作的控制平面。
02 · 七个月冲到 10.6 万星
2026-03-02 建仓，10-23 实查已有 106,201 stars、17,660 forks，且当天仍在推代码；累计合并超 2,700 个 PR。这个涨速放在 AI 基建赛道也属第一梯队。
03 · 任何 Agent 都能"入职"
内置 Claude Code、Codex、Cursor、Gemini CLI、OpenCode、Kimi Code、Hermes 等 10+ 适配器，README 的原话是："能收到心跳（heartbeat）的，就算录用。"
04 · 用 AI 开发"管理 AI 的系统"
仓库本身就是 AI 驱动开发的样板：PR 由 Claude、GPT 系模型编写并合著，Greptile AI 代码评审要求 5/5 满分门禁，单个 PR 要过 194 项工作流测试 + 3,963 项 UI 测试。

三、它到底管什么：四大支柱
01Agentic Task Manager面向所有人
把 Agent 的工作装进票据系统。任务票据化、对话线程化，会话跨重启持久；审批与 review gate 内建；routines 按计划自动创建任务，产出用 diff、截图、测试结果验证。
为什么关键：没有它，你开着 20 个 Claude Code 终端 tabs，重启全丢；有了它，想法变成一张任务票，coding agent 做完、管理层审查即可。
work & task system · atomic checkout
02Org Chart for Agents面向管理者
给 Agent 发工牌、定职级、画汇报线。人与 Agent 混合的组织架构，任务沿汇报线委派流动；"你的 Agent 有老板、有头衔、有岗位说明书。"
为什么关键：委派有了结构，权限才能收敛——scoped secrets、连接权限、responsible-user 身份归因都挂在组织架构上。
org chart · governance · approvals
03Agent Employee Training面向赋能者
技能是全公司的资产，不是个人的配置文件。Skill Studio 编写共享技能，保存输入测试与 evals，技能有版本历史可回滚，还有现成的团队模板一键安装。
为什么关键：Agent 在运行时注入技能与项目上下文，不用重训练——"员工培训"第一次有了工程化路径。
skill studio · evals · team templates
04Agentic OS面向 IT / 平台
跨 provider 的运行时底座。沙箱（e2b、Cloudflare、Daytona、Modal、K8s）、MCP server 接入、SSO/RBAC、成本控制、运行历史与可选 tracing。
为什么关键：预算按 company/agent/project/goal/provider/model 七个维度追踪，达到限额自动暂停——AI 失控烧钱这件事第一次有了硬刹车。
sandbox · mcp gateway · budget control
四、真正管住 Agent 的几个机制
· Heartbeats 心跳唤醒：Agent 因被分配工作、收到跟进消息或到达计划时间而唤醒，委派沿组织架构上下流动；
· Atomic task checkout：任务单一认领人 + 执行锁，多 Agent 并发不抢票；
· Goal alignment：任务携带目标血缘（goal ancestry），Agent 干活时自带"公司要什么"的上下文；
· Governance with rollback：审批门强制执行、配置版本化，出问题可安全回滚；
· Accountable connections：人类访问、Agent 资格、gateway 权限三者分离，MCP 动作可设 Allowed / Ask first / Off；
· Company portability：整个"公司"可导出导入，含 secret 清洗与冲突处理。
五、三步上手
① 定目标（如"做到 AI 笔记第一、1M MRR"）→ ② 招团队（CEO、CTO、工程师、设计师、营销，任何 bot、任何 provider）→ ③ 审批开跑（审查策略、设预算、启动、监控）。需要 Node.js 24.11+，一条命令安装：
$ npx paperclipai@latest onboard --yes
$ npx paperclipai configure   # 修改配置
$ ANTHROPIC_API_KEY=... npx paperclipai test-drive
# 体验模式：--harness codex / --model / --data-dir
生产部署指向自己的 PostgreSQL，支持认证模式 + Tailscale 私网绑定或 Docker。默认开启匿名遥测，介意可用 PAPERCLIP_TELEMETRY_DISABLED=1 关闭。
六、谁该关注它
如果你同时在开 20 个 Claude Code 终端并已经跟丢；如果你想让 Agent 7×24 自主干活但必须可审计、可介入、可断供；如果你的团队同时用 Claude、Codex、Cursor 却各管各的——Paperclip 就是缺的那一层。它的口号值得再读一遍：Manage business goals, not pull requests.
