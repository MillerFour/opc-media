> 版本 v1 ｜ 2026.11.06 ｜ 配套已发：其一《钢铁帝国里走出的天才》（羊皮卷，blackgold）
> 本文件是系列生产用的工作底稿：每章可独立成篇，但所有章节共享同一套暗线与钩子链。

## 一、系列定位

| 项 | 定义 |
|---|---|
| 系列名 | **哲人档案 · 维特根斯坦**（封面 tag：PHILOSOPHER ARCHIVE） |
| 主标题格式 | 维特根斯坦·其N：XXXX（正文大标题可用副题变体） |
| 风格 | 羊皮卷（叙事/历史），封面双比例，正文配图 2 张，做旧信息图或 AI 图 |
| 目标读者 | 听过"语言的边界就是世界的边界"但没读过原著的人；想理解分析哲学入门的中文读者；对"天才人生"有好奇心的人 |
| 差异化 | 市面传记（蒙克、江怡）是"学术传记"，本系列是**章节化、故事驱动、每篇解决一个具体困惑**的连载 |
| 单篇体量 | 2500–3500 字，五章结构（引子 + 3–5 章 + 结语），年表/口径/互动作为固定尾件 |
| 更新节奏 | 每篇 1 次推送，间隔 3–7 天；每篇末尾固定"下期预告 + 评论区点单" |

**总纲心法**：一篇只回答一个问题。哲学概念不做百科式罗列，一律挂在一个人生场景上——他为什么在战壕里想通命题是图像，比"图像论定义"重要十倍。

### 其二 ｜《七个命题：一本想终结哲学的书》

- **主问题**：一本不足八十页的书，凭什么宣称"哲学问题已被彻底解决"？
- **切口故事**：1916 年战壕里那张报纸——汽车事故示意图让他突然明白"命题是现实的图像"；四年后战俘营里，这个直觉长成了七个编号命题。
- **核心概念（不超过 5 个，逐个配生活例子）**
  1. 世界是事实的总和，不是物的总和
  2. 命题是现实的图像（图像论 / 逻辑形式）
  3. 真值函项：复合命题由基本命题算出
  4. 可说的与不可说的（语言的边界）
  5. 第 6.54 条的梯子：说完就得扔掉
- **钉子句**："他用一本书给哲学结了案，然后辞职去山村教书——这个决定，比书本身更像宣言。"
- **配图**：命题—图像的对应结构图；七个主命题的层级树
- **钩子（接其一）**："他说'凡不可说的，必须保持沉默'。可沉默的那部分，恰恰是他一生最放不下的——这成了他后来全部转向的起点。"

### 其三 ｜《不要想，而要看：语言游戏的发明》

- **主问题**：如果语言不是一张精确的地图，那它是什么？
- **切口故事**：1929 年回到剑桥，他发现自己那本"结案之作"错了；此后二十年，他在讨论班上反复用同一个动作开场——"别找定义，看它怎么用"。
- **核心概念**
  1. 意义即用法（反对指称论）
  2. 语言游戏：下棋、点菜、报数、骂人
  3. 家族相似：为什么"游戏"没有共同本质
  4. 遵守规则的悖论（§201）：规则不能替你决定下一步
  5. 哲学是治疗：不是解决问题，是消解问题
- **钉子句**："前期他要给语言画边界，后期他说边界根本画不出来——语言不是地图，是活动。"
- **配图**：语言游戏九宫格；"游戏"家族相似关系网
- **钩子（接其二）**："如果意义只在用法里，那'我疼'这句话的用法是什么？——下一章，那个盒子里的甲虫。"

### 其四 ｜《盒子里的甲虫：私人语言为什么不可能》

- **主问题**：我的感受，能不能有一种只有我懂的语言？
- **切口故事**：小时候他问"撒谎为什么不对"；长大后他问"你怎么知道我疼"。同一个问题的两个版本——都是关于"内部的东西能否公开"。
- **核心概念**
  1. 私人语言论证（§243–315）
  2. 甲虫比喻：盒子里的东西在语言游戏里"掉出画面"
  3. "疼"的语法：不是描述对象，是替代哭喊
  4. 内省主义与行为主义的双重陷阱（他不是行为主义者）
  5. 心理哲学后期笔记：面相知觉、 Seeing-as
- **钉子句**："如果狮子会说话，我们也听不懂它。——不是它说得不清楚，是我们的'生活形式'不重叠。"
- **配图**：甲虫盒子示意；"疼"的三种用法对照
- **钩子（接其三）**："语言的用法是被训练出来的。那么数学呢？数学里的规则，是谁训练的？"

### 其五 ｜《规则没有说明书：数学基础与那堂有图灵的课》

- **主问题**：2+2=4 为什么不容反驳？规则的必然性从哪来？
- **切口故事**：1939 年剑桥讲席课，图灵坐在台下，为"数学的可靠性"与他正面交锋——两个改变二十世纪的人，为同一件事吵了一整个学期。
- **核心概念**
  1. 规则遵循与"生活方式"（不是约定论，也别读成相对主义）
  2. 数学命题是语法命题，不是经验描述
  3. 证明的"看": 证明改变的是我们看它的方式
  4. 与哥德尔、希尔伯特纲领的距离（讲清误读）
  5. 矛盾与"不一致的演算"
- **钉子句**："他不是说数学是随便的，他说的是：数学的硬度来自我们的实践，不来自天上。"
- **配图**：规则悖论的分岔树；图灵—维特根斯坦课堂对位卡
- **钩子（接其四）**："讲完最硬的一章，回到最软的一章——他一生真正在意的，其实是伦理。"

### 其六 ｜《把世界当作一个整体来看：伦理学、战争与自我》

- **主问题**：既然伦理"不可说"，他为什么一辈子都在为它受苦？
- **切口故事**：1916 年战地笔记里那些近乎祈祷的句子；1929 年《关于伦理学的讲演》里，他承认"讲伦理学等于撞墙"；临终那句"我度过了极好的一生"。
- **核心概念**
  1. 伦理是超验的：不能给出规范，只能显示
  2. 魏宁格《性与性格》与"逻辑与伦理是一回事"
  3. 罪、忏悔与自我清算（对亲友的告白）
  4. 神秘主义：不是不可知，是不可说
  5. 宗教：不是论证，是生活方式
- **钉子句**："他把伦理赶出了语言，却把自己的一生押在了伦理上——这不是矛盾，这是他唯一能自洽的方式。"
- **配图**：可说/不可说的分界地图（伦理、美学、宗教落在哪一侧）；战地笔记结构
- **钩子（接其一与全系列）**："八岁那个问题到这里才有答案：诚实不是一条规则，是一种活法。"

### 其七 ｜《被误读的天才：遗产、门徒与"维特根斯坦产业"》

- **主问题**：他死后七十年，谁在继承他，谁在消费他？
- **切口故事**：1953 年《哲学研究》出版，学生安斯康姆与冯·赖特整理遗稿；同一时期，维也纳学派把他的前期著作读成"逻辑实证主义圣经"——他本人当场否认。
- **核心概念**
  1. 维也纳学派的误读与他的愤怒
  2. 剑桥门徒：安斯康姆、马尔科姆、冯·赖特
  3. 遗稿 Nachlass 与电子版：为什么"未定稿"才是他的真实形态
  4. 中译史：《逻辑哲学论》《哲学研究》几代译本差异
  5. 流行文化的鸡汤化："语言的边界"如何变成励志金句
- **钉子句**："他一生反对被系统化，结果被做成了无数个系统。"
- **配图**：传承谱系图；误读对照表（原话 vs 流行版本）
- **钩子（收束全系列）**："读懂他不需要崇拜他。下一季如果还写，就写他的对手：罗素、弗雷格、图灵。"

## 三、贯穿全系列的四条暗线

| 暗线 | 起点（其一） | 中间落点 | 收束 |
|---|---|---|---|
| **诚实** | 八岁"为什么不说谎" | 战壕、乡村教师的失败、忏悔 | 遗言"极好的一生" |
| **语言的边界** | 工程师追问数学的可靠性 | 图像论 → 语言游戏 → 私人语言 | "不可说"的那一半 |
| **自我清算** | 散尽家产、拒绝家族 | 辞讲席、住村舍、拒绝被系统化 | 遗稿的反体系形态 |
| **逃亡与回归** | 维也纳 → 柏林 → 曼彻斯特 | 山村 → 修道院 → 造屋 → 剑桥 | 挪威/爱尔兰小屋 → 剑桥病逝 |

写作纪律：**每篇至少回扣两条暗线**，用一句话点明，不要长篇复述前情（系列读者会跳读）。

## 四、每篇的固定结构模板

1. **引子（约 300 字）**：一个场景或一句原话，直接抛主问题，不铺垫背景
2. **三到五章正文（每章 500–700 字）**：章节标题用中文序数 + 一句判断句，不用"什么是XX"式教科书标题
3. **【手记】卡 ×2–3**：每章末一句判断，可独立引用（这是被转发的主力）
4. **结语（约 300 字）**：回到主问题，给出一个明确判断，留一句下期钩子
5. **附**：年表或对照表（表格形式）、口径说明、互动提问
6. **素材**：封面 2.3 深蓝 + 方版 1x1（沿用其一模板，只换期号与年份条）；插图 2 张（做旧信息图优先，AI 图仅兜底）

## 五、选题风险与口径（必读）

| 风险点 | 处理方式 |
|---|---|
| 生平轶事真伪混杂（答辩拍肩、遗言等） | 正文照写，口径说明标注"学界广为流传的轶事记载"，不伪装成一手史料 |
| 家族犹太血统与时代政治 | 只按传记事实陈述家族同化与自我认同，不做时代政治延伸 |
| 情感与性取向 | 按蒙克传记据实、克制陈述，不做猎奇化描写，不引未证传闻 |
| "天才崇拜"腔 | 每篇至少一处写他的失败（体罚事件、与罗素的决裂、被维也纳学派误读），禁止通篇造神 |
| 哲学解释分歧 | 概念解释以通行学界共识为限，遇到争议（如私人语言论证的强弱读法）明说"有两种读法" |
| 鸡汤化 | 禁用"改变认知的十个道理"式标题；原话必须给上下文 |
| AI 图水印 | 优先做旧信息图（HTML 绘制截图）；AI 图仅兜底，且不裁不遮水印 |
