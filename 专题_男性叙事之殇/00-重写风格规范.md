# 专题写作风格规范（2026.11.24 定稿 · 28篇版）

标杆文件：`起点_那个凌晨_2026.11.24/正文.html`。写任何一篇前，先完整读标杆，再读 `00-专题说明.md` 的篇目锚点。

## 〇、视觉风格（参考「AI意识觉醒」公众号）

- 白底卡片（`#fff`），不用档案纸底；正文 15px / 行高 1.85
- 蓝色小标题竖线（`#1a6fb5`），小标题是白话短句或问句
- 📌 提示框（浅蓝底 + 蓝竖线）：放一个最值得记住的数字或判断
- ✍️ 互动收尾框：向读者提问 + 点赞在看引导 + 下一篇预告
- 文末「参考」区：灰色小字，自然列清来源，零角标
- 报头不要「篇 xx/28」，用「社会观察 · 锚点一句话」

## 一、声音：老编辑，柔软，有温度

- **从画面进场，不先下判决。** 用一个具体场景、一个细节、一句原话开场，让读者自己走进去。禁止「这一篇看的是……」「要回答的问题是……」这类开场。
- **允许「我」出现。** 「我每次翻到这条评论都觉得……」「这话你未必同意」「十年后看，笑不出来」。有观察者的体温，但不写「作为男人我如何如何」。
- **敢下判断，但不硬邦邦。** 短句跟在长句后面，像谈话的停顿：『这不是阅读。这是全网停下手里的事，围过来看。』
- **叙述有层次和完整性。** 一段只讲一件事，讲完再走。禁止一段没说完就跳下段接着衔接。

## 二、读者可见文字里禁止的车间黑话

- 阶段词：产生期 / 演变期 / 常态化 / 产生 / 演变 / 常态
- 自指词：本篇 / 本文 / 这一篇 / 专题 / 读者先看懂 / 下面要拆 / 这条纪律 / 见注 / 写作纪律 / 观察性结论 / 机制分析能回答
- 进度词：篇 01/14 / 11/14 / 阶段 / 角度 / 矩阵 / 锚点
- 上述词只允许出现在 HTML 注释（`<!-- -->`）中，或 `资料来源` 区之外不可见的地方。标题区副题写成一句生活化的引导语，如「从一个睡不着的凌晨讲起。」

## 三、标点（硬规范）

- 中文语境一律全角：？！，。；：
- 禁止半角 `! ?` 出现在中文后（如 `!!!`、`情况!?`、`出轨?`）
- 禁止标点连用异常（如 `：。`，`，。`）
- 引号内完整句，句号放引号内；非完整引用，句号放引号外
- 数字、英文、年份保留半角

## 四、段落（硬规范）

- 每段 80–140 字，平均 70 字左右，**最长不超过 140 字**
- 一段一个完整意思：画面 / 动作 / 感受分开成段
- 段落之间不写「接着说」「上面说到」这类连接词，靠内容本身的逻辑推进

## 五、角标与出处（硬规范）

- 正文**零上标角标**，不出现 `<sup>`，不出现 `[1]` 这类数字编号
- 文末区块标题改为：**资料来源**
- 资料来源用自然清单：一行一个来源，写清机构/篇名/日期/关键数据，不加编号
- 引文卡底部出处说明不写「见注 [n]」，直接写来源与立场
- 保留原文里的事实、数据、引语、出处信息，只改变呈现方式——**不能丢失任何硬信息**

## 六、结构（照抄标杆，不要改 HTML）

- 保留全部 `<section>`、`<p>` 标签及其 style 属性，保留引文卡、机制图 `<img>`、报尾
- 只替换文字内容：标题区副题、导语、正文段落、引文卡文案、文末区块、资料来源、口径说明、出口
- 报头右侧只留日期（如 `2026.11.24`），不带「篇 xx/14」
- `<title>` 只写文章标题，不加副标
- 头部 HTML 注释可以保留阶段、角度、风格信息（读者不可见）

## 七、写作纪律（继承专题总纪律）

1. 观察者立场，作者性别不作论证依据，不站任何性别
2. 批评结构不攻击群体
3. 事实观点分离；单方口述注明；两面解释并列
4. 敏感指控不转述、不评价
5. 个案不上升群体本质
6. 「魔法对轰」写清代价，不写成爽文或行动指南
7. 每篇结尾给可讨论方向，不落绝望、不给鸡汤
8. 小红书写机制不写恶，治理数据两面并陈

assert max(len(x) for x in core) <= 140, '段落超长'
