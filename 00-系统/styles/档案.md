# 风格卡 · 档案（ARCHIVE）

```yaml
style_id: archive
name: 档案
aliases: [社会学观察, 机制溯源, archive]
best_for: 社会学观察 / 机制拆解 / 跨事件溯源 / 专题长文
cover_theme_id: blackgold
added: 2026.11.23
scope: 专题专用（男性叙事之殇）

assets:
  body: "00-模板/档案/正文.html"
  cover: "00-模板/档案/封面.html"
  cover_generator: null
  illustration: "00-模板/档案/插图.html"
  metadata: "00-模板/档案/元数据.md"

palette:
  paper: "#f2efe6"     # 档案纸底，微微泛黄
  paper_dark: "#eae6da" # 引文卡 / 口径说明
  line: "#cfc9ba"
  ink: "#1f1d1a"       # 深墨，非纯黑
  body: "#33302a"
  sub: "#6b6659"
  faint: "#8a8375"
  accent: "#3d6470"    # 石板青，唯一强调色（避开黑/金蓝/红/朱砂/绿）

skeleton:
  - 报头：细线式，左「ARCHIVE · 档案 N」+ 右日期，下方 2px 深墨线
  - 标题区：宋体 26px 判断句 + 灰副题说清观察范围，下方 1px 细线
  - 导语：2-3 句，第一句必写「这一篇看的是产生/演变/常态化哪一段」
  - 正文：长段落 15px/1.95，左对齐；强调只用加粗；出处用上标 [n]
  - 章节眉：1px 细线 + 小字「I · 章节名」，不用色块徽章
  - 引文卡：浅纸底 + 3px 石板青左竖线 + 编号 + 来源立场标注
  - 机制图位：<img src="插图_1_xxx.jpg"> + 图注
  - 注区：2px 深墨顶线 +「注 · SOURCES」+ [1][2][3] 逐条
  - 口径说明 + 出口段 + 「— 档案终结 · ARCHIVE CLOSED —」

rules:
  - 所有 section 显式 text-align:left（报尾居中例外）
  - 上标编号 [n] 与文末注一一对应，不得孤立
  - 引文必须写来源立场（企业方/学界/当事方），同一现象两种解释并列
  - 段落允许长，靠论述密度推进，不做要点卡堆砌
  - 数据写在行内文字里，注明数值与口径

forbidden:
  - 彩色高亮（石板青以外）、渐变、阴影、大色块头部
  - 把单方主张写成事实
  - 道德标签（「最大的恶」这类）
  - 写成操纵舆论的行动指南
  - AI 生图做插图

tone:
  default: 慢、沉、平视、有距离的社会学观察
  verdict: 不下道德结论，给可讨论方向
```
