# 风格卡 · 锌白（Zinc Weekly）

> 写作时只读这一张卡 + `00-模板/style-锌白.html` 骨架，不要全量读 style-guide。

```yaml
style_id: zinc
name: 锌白
aliases: [周报, 终端风, zinc]
best_for: 科技 / 数据 / 清单 / 人物档案 / 系列长篇
cover_theme_id: terminal

palette:
  bg: "#ffffff"
  ink: "#09090b"      # 标题、强调、正文黑
  sub: "#52525b"      # 次级正文
  mute: "#71717a"     # 辅助说明
  faint: "#a1a1aa"    # 页脚
  line: "#e4e4e7"     # 边框
  wash: "#fafafa"     # 要点卡底
  dark: "#09090b"     # 头部卡黑底

skeleton:
  - 头部黑卡：眉标 12px 字距 3px → 标题 24px/700 → 导语 13px
  - 章节标题：17px/700，中文序数
  - 要点卡 ×N：左 3px 黑竖线 + #fafafa 底
  - 数据卡 / 对照表：白底 1px 边框，等宽字体
  - 附录卡：清单或年表
  - 口径说明卡 + 结尾互动

rules:
  - 每个 section 显式写 text-align:left（否则公众号排版会飘）
  - 强调只用 <b> 加粗，不染色
  - 数据、年份、文件名用 Consolas 等宽
  - 人物档案类：每篇至少一处"不套模板"的场景描写

forbidden:
  - 彩色高亮、渐变、阴影
  - 用 AI 生图做封面
  - 通篇排比句式的"硬货"腔（读者会累）

tone:
  default: 克制、直接、有判断
  warm_variant: 人物/家庭题材可放缓节奏，用场景推进，少下判断句
```
