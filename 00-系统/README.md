# 00-系统 · 公众号创作系统

一个给「系列创作」和「随笔创作」共用的状态与流水线层。

| 目录 | 内容 |
|---|---|
| `系统规划.md` | 完整设计：分层、模块、状态机、路线图、反模式 |
| `styles/` | 风格卡（每张 ≤300 字，写作时只读一张） |
| `data/topics.yaml` | 选题池 |
| `schema/` | manifest / series 模板 |
| `tools/` | `sys.py`：状态看板、素材、推送（P1 阶段先做 status） |

**三条铁律**
1. 状态只由脚本改，agent 不手改。
2. 写作归 agent，记账与发布归脚本，决策归你。
3. 事实核查、口径、发布前预览三道人工卡点不自动化。
