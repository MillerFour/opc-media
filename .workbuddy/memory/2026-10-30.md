## Git 自动提交（githook 方案落地）
- 结论：git 没有文件生成事件，`pre-commit/post-commit` 只在 commit 时触发 → 必须"监听器 + 钩子"两层。
- 新增：`scripts/autocommit.sh`（一次性提交，msg 带顶层目录统计）、`scripts/watch-commit.sh`（轮询 + 静默一周期防碎片提交，pid 锁 + .watch.log）、`scripts/start-watch.bat` / `stop-watch.bat`（Windows 双击，自动探测 bash.exe）、`scripts/README.md`。
- 钩子：`.githooks/pre-commit` 拦 >30MB 与 *.tmp/*.log；`.githooks/post-commit` 写 `.git/autocommit.log`；已设 `core.hooksPath=.githooks`、`core.quotepath=false`。
- `.gitignore` 加 scripts/.watch.pid、scripts/.watch.log、*.tmp、.tmp-*。
- 实测通过：16 项变更提交成功；pre-commit 正确拦下 31MB 文件与 hooktest.log；watcher（INTERVAL=2）在写入后 2 秒内自动提交。
- 踩坑：awk 单行 `if (...) print x else print y` 必须加花括号，否则 syntax error，导致 commit body 为空。
