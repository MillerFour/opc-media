# 项目长期记忆（wx-mp 公众号资料库）

## 文件命名规则（强制，永久生效）

用户每天在此文件夹存放公众号创作资料。所有我生成的交付文件**必须**遵守以下命名格式：

```
日期_标题_说明.后缀名
```

- **日期**：`YYYY.MM.DD`（点分隔，如 `2026.10.23`）
- **标题**：文章/作品标题（如 `PHP2Shell漏洞始末`）
- **说明**：内容形态/尺寸/用途描述（如 `方版1x1`、`浅色`、`2.3比例封面`）
- **分隔符**：下划线 `_`
- **示例**：`2026.10.23_PHP2Shell漏洞始末_方版1x1.png`、`2026.10.22_GitHub涨星TOP10-浅色.png`（旧文件，标题内用连字符属历史习惯，新文件一律用下划线分段）

任何创作任务（文章、封面图、配图、HTML 等）产出的文件名都按此规则生成，保证日积月累不乱。

## 文章与封面风格（强制，永久生效）

基线参考：`2026.10.22_GitHub涨星TOP10.html`（正文）+ `cover-design.html`（封面模板）。完整规范见 `E:\Writing\wx-mp\.workbuddy\style-guide.md`，每次创作前先读它。

核心要点：
- 正文：公众号适配版 HTML，**全内联样式**（section 嵌套，无外部依赖，粘贴即用），所有 section 显式 `text-align:left`；zinc 黑白灰单色系（#09090b 主黑 / #52525b 次级 / #71717a 辅助 / #e4e4e7 边框 / #fafafa 浅底），无彩色；结构 = 黑底头部卡 → 中文序号章节 → 要点卡（左3px黑竖线）→ 数据卡（纯 span 条形图）→ 白底条目卡（序号水印+徽章+右浮星数）→ 等宽附录 → 口径说明 → — 完 —。
- 封面：zinc 风格 900×383（2.3比例）+ 900×900（方版1x1）两种规格都要；网格背景+光晕、tag 药丸、大标题 800 字重、右侧终端卡（三圆点+等宽命令+星数条）；主交付浅色版。
