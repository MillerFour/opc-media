## 文件命名规则（强制，永久生效）

```
日期_标题_说明.后缀名
```

- **日期**：`YYYY.MM.DD`（点分隔）；**标题**：文章标题；**说明**：内容形态（如 `方版1x1`、`2.3浅色`）
- **分隔符**：下划线 `_`；示例：`2026.10.23_PHP2Shell漏洞始末_方版1x1.png`
- 归档夹内文件用语义短名（正文/封面_xxx/插图_x），文件夹名本身承载日期与标题
