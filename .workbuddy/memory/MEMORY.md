## 专题目录结构（强制，2026.11.23 起）

专题与普通文章分开归档。**一个专题 = 一个独立文件夹；专题内按「角度 + 时间」建子文件夹；子文件夹里才放实际图片与 HTML。**

```
E:\Writing\wx-mp\
└── 专题_{专题名}\                    # 一个专题一个夹，加「专题_」前缀与普通文章夹区分
    ├── {角度}_{YYYY.MM.DD}\          # 子夹命名：角度在前、日期在后（用户 2026.11.23 定）
    │   ├── 正文.html
    │   ├── 封面_2.3xxx.png / 封面_方版1x1.png
    │   ├── 插图_1_xxx.jpg
    │   └── 源文件\                   # cover.html、fig-*.html、cfg.json 等
    ├── {角度}_{YYYY.MM.DD}\          # 同一角度可有多个时间点；不同角度各自成夹
    └── 00-专题说明.md                # 选填：专题缘起、角度清单、进度台账
```

- **命名顺序**：`{角度}_{日期}`，不是日期在前——同一角度的多篇能聚在一起，便于按角度追踪
- **日期格式**：`YYYY.MM.DD`（点分隔），与普通文章的命名规则一致
- **角度**：用短语，不用序号（如 `员工联署`、`股权结构`、`主视觉`），可读优先
- 夹内文件名用语义短名（正文 / 封面_xxx / 插图_x），跟普通文章夹一致
- 专题是独立资产，**不塞进 `日期_标题` 文件夹，也不往根目录平铺图片**
- 以后所有专题创作一律按此结构；已有文章不追溯迁移

## 文件命名规则（强制，永久生效）

```
日期_标题_说明.后缀名
```

- **日期**：`YYYY.MM.DD`（点分隔）；**标题**：文章标题；**说明**：内容形态（如 `方版1x1`、`2.3浅色`）
- **分隔符**：下划线 `_`；示例：`2026.10.23_PHP2Shell漏洞始末_方版1x1.png`
- 归档夹内文件用语义短名（正文/封面_xxx/插图_x），文件夹名本身承载日期与标题

## 插图素材策略（2026.10.27 补充）

- **AI 生成图自带合规水印（AI 内容标识法规），不可去除、不可裁剪规避**
- 素材优先级：官方素材/新闻图/视频截图 > 可商用图库 > AI 生成兜底；热点与游戏题材尤其优先实拍素材
- 使用官方/媒体图片时图注标明来源（如"图源：奥迪"）
- **官网素材抓取（2026.11.16 补充）**：官网多为 JS 渲染，`grep img src` 常抓不到；改用 AEM 路径 `www.nvidia.com/content/dam/en-zz/Solutions/...`、新闻稿图 `iprsoftwaremedia.com/219/files/...`、社媒 OG 图 `.../social-image/xxx-og-1200x630.jpg`。图源分辨率天花板常只有 1200×630，**低分辨率人像用「精确裁切 + 双色调映射 + 颗粒噪点」做海报化处理**，糊感会变成风格感，比硬放大强。黑色底的白色 logo 需反相去底（亮度阈值生成 alpha）
- **竖屏封面规格（2026.11.16）**：小程序竖屏用 **1080×1440（3:4）**，同系列出 3 张不同角度（主视觉 / 数据 / 结构），PNG 与 JPG 各存一份；成品放文章夹 `竖屏图/`，源文件与素材放 `源文件/竖屏/`（HTML 引用 `素材/xxx`）

## Git 自动提交（强制，2026.10.30 起）

- 仓库已有 remote：github.com/MillerFour/opc-media（默认只 commit 不 push）
- **每完成一篇文章/一批素材，收尾必须执行 `bash scripts/autocommit.sh`**，别攒着（用户明确要求"生成完文件自动提交"）
- 三层结构：`scripts/watch-commit.sh`（轮询监听 + 静默一轮再提交）/ `scripts/autocommit.sh`（一次性提交，msg 自动带顶层目录统计）/ `.githooks/*`（pre-commit 拦 >30MB 与 *.tmp/*.log，post-commit 记 `.git/autocommit.log`）
- `git config core.hooksPath .githooks` 已设；新机器 clone 后需重设一次
- 常驻监听：`scripts/start-watch.bat`（最小化）/ `scripts/stop-watch.bat`；**不做开机自启**（用户 2026.10.30 明确否掉），由 agent 会话内手动拉起，会话结束即失效
- 因此真正兜底的是「每篇收尾调 autocommit.sh」，不依赖常驻进程

- **默认自动 push**（2026.10.30 用户确认）：提交后自动 `git push origin HEAD`，`AUTO_PUSH=0` 可临时关掉；推送前判断本地领先数，干净工作区也会补推
- 细节见 `scripts/README.md`
