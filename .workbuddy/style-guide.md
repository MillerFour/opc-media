## 风格 A：锌白（Zinc Weekly）

参考基线：`00-模板/style-锌白.html`（正文模板）+ `00-模板/cover-锌白.html`（封面模板）。实例见 `2026.10.22_GitHub涨星TOP10/正文.html`。

## 一、正文 HTML 风格（公众号适配版）

### 总体
- 单文件 HTML，全内联样式（section 嵌套 + inline style），不依赖外部 CSS/JS/图片——直接粘贴进公众号编辑器即可用。
- `<style>` 块仅用于本地预览（body 灰底 #f4f4f5），并注释说明"粘贴到公众号编辑器时会被丢弃"。
- 外层容器：`max-width:677px; margin:0 auto; background:#ffffff; padding:28px 20px 36px;` 字体栈 `-apple-system,BlinkMacSystemFont,'PingFang SC','Microsoft YaHei',sans-serif`。
- **所有 section 显式 `text-align:left`**（公众号合规要求，一个都不能漏）。
- 起止处放复制范围注释：`<!-- 外层容器：复制时从这一行下方开始全选 -->` … `<!-- 复制到此行为止 -->`。

### 色彩体系（zinc 单色，黑白灰，无彩色）
| 用途 | 色值 |
|---|---|
| 主标题/强调/正文黑 | #09090b |
| 条形图填充/左竖线 | #18181b |
| 次级正文 | #52525b |
| 辅助说明 | #71717a |
| 弱化/页脚 | #a1a1aa |
| 序号水印大数字 | #d4d4d8 |
| 边框 | #e4e4e7 |
| 浅灰底（要点卡/附录底） | #fafafa |
| 轨道/预览底 | #f4f4f5 |
| 卡片底 | #ffffff |
| 头部卡黑底 | #09090b（内文字 #fafafa / #a1a1aa / #71717a） |

### 文档结构（自上而下）
1. **头部卡**：#09090b 圆角12px；眉标（12px/600/letter-spacing:3px/#a1a1aa）→ 大标题（24px/700/#fafafa/letter-spacing:-0.5px）→ 来源与导读（13px/#71717a/line-height:1.8）。
2. **章节标题**：17px/700/#09090b/letter-spacing:-0.3px，中文序号「一、二、三、」。
3. **核心要点卡**（N 个）：`border-left:3px solid #18181b; background:#fafafa; border-radius:0 8px 8px 0;` 标题 14.5px/600 + 正文 13.5px/#52525b/line-height:1.75。
4. **数据卡**：白底 + 1px #e4e4e7 边框圆角8px；条形图用纯 span 堆叠实现（label 定宽 + 数值 + `height:6px; border-radius:99px` 圆角条），等宽小字标题。
5. **条目卡**（列表主体）：白底 1px 边框圆角10px；行内布局 = 序号水印（20px/700/#d4d4d8）+ 名称（16px/700）+ 语言徽章（11px/#71717a 圆角99px 边框）+ 右浮星数（12.5px/600）。正文 14px，加粗金句开头；「为什么火：」13px/#71717a 加粗黑前缀；末行等宽 12px/#a1a1aa 放链接/出处。
6. **附录卡**：#fafafa 底 + Consolas 等宽 12.5px，用 `··········` 点线对齐清单。
7. **口径说明卡**：#fafafa 底，13px/600 黑标题 + 12.5px/#71717a 列表（· 开头）。
8. **结尾**：居中 `— 完 —`（12px/#a1a1aa）。

### 排版参数
- 正文 13.5–14.5px，标题 16–24px，行高 1.75–1.8；数据/代码用 `Consolas,monospace`。
- 强调只用 `<b>` 加粗 + 色号分级，不用彩色高亮。
- 卡片间距 10–12px，章节间 28–30px。

## 二、封面图风格

- 模板：`00-模板/cover-锌白.html`（zinc 双主题，light 为主交付，dark 备用）。
- 规格：**两种比例都要**——消息列表 2.35:1（900×383）+ 转发卡片/主页 1:1（900×900 方版，竖排布局：标签/标题/全宽终端卡/底部标语）。
- 视觉元素：
  - 网格背景（44px 网格 + radial mask 聚焦左中）+ 右上光晕（径向渐变，极低透明度）；
  - 左侧：tag 药丸（圆点 + 11.5px/600/letter-spacing:.14em 边框圆角）→ 大标题（54px/800/letter-spacing:-0.035em/nowrap，数字部分 tabular-nums 用次级灰）→ 副标题（17px，关键词加粗黑）；
  - 右侧：终端卡（330px 宽，圆角14px，三圆点标题栏 + 等宽命令行 `$` 前缀 + 星数行：数值+6px圆角条+名称）；
  - 左下 foot：短横线 + 11.5px 字距标注。
- 浅色主题变量：底 #fafafa，fg #09090b，muted #52525b，边框 #e4e4e7，条形 fill #18181b / track #f4f4f5。
- 交付：按命名规则出 PNG（如 `YYYY.MM.DD_标题_2.3比例封面.png`、`YYYY.MM.DD_标题_方版1x1.png`），保留源 HTML。
- 截图踩坑：clip 超出视口需 `fullPage:true`，坐标用 `getBoundingClientRect + scrollY` 换算。

## 三、交付清单（每篇文章标配）
1. 正文 HTML：`日期_标题.html`（公众号适配版，全内联样式）
2. 封面 PNG ×2：`日期_标题_2.3比例封面.png` + `日期_标题_方版1x1.png`

## 风格 B：羊皮卷（Chronicle · 2026.10.24 新增）

参考基线：`00-模板/style-羊皮卷.html`（正文模板）+ `00-模板/cover-羊皮卷.html`（封面模板，navy/cream 双主题）。实例见 `2026.10.24_魔兽编年史导读/正文.html`。

### 正文要点
- **纸张**：外层底 `#faf7ef`（羊皮纸米色），本地预览底 `#e8e4d8`；卡片底 `#f5f0e2`，白卡 `#ffffff`，边框 `#e6dfcd`。
- **头部卡**：深蓝夜空 `#0d1526` + 边框 `#2a3550`；金色眉标药丸（11.5px/600/字距3px/`#c9a24b`）；标题 24px/700 `#f3ead2` **宋体系**（`'STZhongsong','STSong','SimSun',serif`）；导语 `#8a94ad`；底部 1px 分隔线 + 卷标导航（`#5a6580`）。
- **章节标题**：金色小字眉（12px/700/`#a88434`/字距3px，如「章 · 一」「卷 · 二」）+ 18px/700 宋体黑标题 `#211d15`。
- **正文**：14.5px `#3d3a33`，行高 1.8，强调用 `<b style="color:#09090b">`；引用卡（米底 + 宋体 `#6b6552`）。
- **手记卡**：左 3px 金竖线 `#c9a24b` + 米底，眉标「XX手记」12px/600/`#a88434`/字距2px。
- **清单卡**：白底圆角10px，条目 `· 加粗小标题　说明文字`。
- **年表卡**：米底附录，条目 = 定宽金色年代标签（min-width:86px）+ 灰棕正文 `#6b6552`。
- **结尾**：互动提问段（14px）+ 居中 `— 完 —`；口径说明米底卡。

### 封面要点（00-模板/cover-羊皮卷.html 两主题）
- **深蓝夜空版（navy）**：底 `#0d1526`，金色网格（rgba(201,162,75,.07)）+ 金色光晕；宋体大标题 `#f3ead2` + 金色年份数字 `#c9a24b`；分隔线卷标；终端卡改深蓝（bg `#111a30`，金 fill 条）。
- **浅色羊皮纸版（cream）**：底 `#faf7ef`，深色字，终端卡为深蓝夜空卡（对比焦点）。
- 其余结构（tag 药丸/foot/方版竖排/slogan）与锌白模板同构，只换配色与字体。

### 选型直觉
叙事型/世界观/历史时间线 → 羊皮卷；科技/数据/清单 → 锌白。插图风格跟随：羊皮卷配版画/做旧风插图，锌白配单色几何风。

## 风格 C：号外（EXTRA · 2026.10.26 新增 · 社会热点专用）

参考基线：`00-模板/style-号外.html`（正文模板）+ `00-模板/cover-号外.html`（封面模板，含预览图）。

### 设计逻辑
社会热点稿的核心诉求：**快、观点前置、事实与观点分离、可引用**。报纸号外的视觉语言天然匹配——新闻纸底、黑粗标题、红章点睛。

### 配色（识别特征）
- 新闻纸米白 `#f7f4ec`（正文底）/ 米灰 `#efeadb`（引语/对照卡）
- 纯黑 `#1a1a1a`（标题/边框/结构）、次级 `#2b2b2b`、辅助 `#6b6552`
- **号外红 `#c9342b`**：仅用于编辑部观点徽章、关键事实/态度词、引语竖线——全文红色 ≤5 处
- 与锌白（黑白灰无红）、羊皮卷（米金深蓝）互斥不撞型

### 正文结构（强制顺序）
1. **报头**：黑边框底 + 左红章「号外 EXTRA」右期号 + 特粗宋体大标题 + 上下双细线关键词行
2. **导语**：加粗报纸腔 2-3 句（发生了什么+为什么值得聊）
3. **快评 · 一/二/三**：黑底白字章节徽章 + 特粗宋体标题；段落短句推进
4. 引语卡（红竖线 + 出处行）、**编辑部观点卡**（黑框 + 红徽章 + 一句钉子话）、立场对照卡（支持方▸/质疑方▸）
5. **后续盯什么 WATCHLIST**：黑底反白跟踪清单（01/02/03，写清判断标准）——本风格灵魂组件
6. 互动（"赞最高的下期单独写"）+ `— 号外完 · EXTRA —` 双细线报尾 + 口径说明（"本栏目不站队、只拆事"）

### 写作纪律
- 标题一句到位不绕弯；导语信息密度拉满无铺垫
- 每段只做一件事：陈述/举例/下判断
- 编辑部观点必须有一句可引用的钉子话；不站队，只拆事

### 封面（cover-号外.html 两画板）
- 2.3 报头版：米白报纸分栏底纹 + 顶部粗黑线 + 红色旋转「号外」章 + 黑宋体大标题（热点六字，可红字点睛）+ 双细线日期/关键词行
- 方版：同语言竖排 + 左下黑底「本期看点」卡（事件/争议/观点三行）+ 右下红色大号期号数字
- 生成参数化时可参照 `cover-generator.py` 的思路，把标题/副题/期号/关键词做成参数

### 选型直觉
社会热点/争议快评/事件跟进 → 号外；科技数据清单 → 锌白；叙事历史游戏 → 羊皮卷。
