## 风格 A：锌白（Zinc Weekly）

参考基线：`00-模板/锌白/正文.html`（正文模板）+ `00-模板/锌白/封面.html`（封面模板）。实例见 `2026.10.22_GitHub涨星TOP10/正文.html`。

## 一、正文 HTML 风格（公众号适配版）

### 总体
- 单文件 HTML，全内联样式（section 嵌套 + inline style），不依赖外部 CSS/JS/图片——直接粘贴进公众号编辑器即可用。
- `<style>` 块仅用于本地预览（body 灰底 #f4f4f5），并注释说明"粘贴到公众号编辑器时会被丢弃"。
- 外层容器：`max-width:677px; margin:0 auto; background:#ffffff; padding:28px 20px 36px;` 字体栈 `-apple-system,BlinkMacSystemFont,'PingFang SC','Microsoft YaHei',sans-serif`。
- **所有 section 显式 `text-align:left`**（公众号合规要求，一个都不能漏）。
- 起止处放复制范围注释：`<!-- 外层容器：复制时从这一行下方开始全选 -->` … `<!-- 复制到此行为止 -->`。

### 色彩体系（zinc 单色，黑白灰，无彩色）
| 用途 | 色值 |
|---|---|
| 主标题/强调/正文黑 | #09090b |
| 条形图填充/左竖线 | #18181b |
| 次级正文 | #52525b |
| 辅助说明 | #71717a |
| 弱化/页脚 | #a1a1aa |
| 序号水印大数字 | #d4d4d8 |
| 边框 | #e4e4e7 |
| 浅灰底（要点卡/附录底） | #fafafa |
| 轨道/预览底 | #f4f4f5 |
| 卡片底 | #ffffff |
| 头部卡黑底 | #09090b（内文字 #fafafa / #a1a1aa / #71717a） |

### 文档结构（自上而下）
1. **头部卡**：#09090b 圆角12px；眉标（12px/600/letter-spacing:3px/#a1a1aa）→ 大标题（24px/700/#fafafa/letter-spacing:-0.5px）→ 来源与导读（13px/#71717a/line-height:1.8）。
2. **章节标题**：17px/700/#09090b/letter-spacing:-0.3px，中文序号「一、二、三、」。
3. **核心要点卡**（N 个）：`border-left:3px solid #18181b; background:#fafafa; border-radius:0 8px 8px 0;` 标题 14.5px/600 + 正文 13.5px/#52525b/line-height:1.75。
4. **数据卡**：白底 + 1px #e4e4e7 边框圆角8px；条形图用纯 span 堆叠实现（label 定宽 + 数值 + `height:6px; border-radius:99px` 圆角条），等宽小字标题。
5. **条目卡**（列表主体）：白底 1px 边框圆角10px；行内布局 = 序号水印（20px/700/#d4d4d8）+ 名称（16px/700）+ 语言徽章（11px/#71717a 圆角99px 边框）+ 右浮星数（12.5px/600）。正文 14px，加粗金句开头；「为什么火：」13px/#71717a 加粗黑前缀；末行等宽 12px/#a1a1aa 放链接/出处。
6. **附录卡**：#fafafa 底 + Consolas 等宽 12.5px，用 `··········` 点线对齐清单。
7. **口径说明卡**：#fafafa 底，13px/600 黑标题 + 12.5px/#71717a 列表（· 开头）。
8. **结尾**：居中 `— 完 —`（12px/#a1a1aa）。

### 排版参数
- 正文 13.5–14.5px，标题 16–24px，行高 1.75–1.8；数据/代码用 `Consolas,monospace`。
- 强调只用 `<b>` 加粗 + 色号分级，不用彩色高亮。
- 卡片间距 10–12px，章节间 28–30px。

## 二、封面图风格

- 模板：`00-模板/锌白/封面.html`（zinc 双主题，light 为主交付，dark 备用）。
- 规格：**两种比例都要**——消息列表 2.35:1（900×383）+ 转发卡片/主页 1:1（900×900 方版，竖排布局：标签/标题/全宽终端卡/底部标语）。
- 视觉元素：
  - 网格背景（44px 网格 + radial mask 聚焦左中）+ 右上光晕（径向渐变，极低透明度）；
  - 左侧：tag 药丸（圆点 + 11.5px/600/letter-spacing:.14em 边框圆角）→ 大标题（54px/800/letter-spacing:-0.035em/nowrap，数字部分 tabular-nums 用次级灰）→ 副标题（17px，关键词加粗黑）；
  - 右侧：终端卡（330px 宽，圆角14px，三圆点标题栏 + 等宽命令行 `$` 前缀 + 星数行：数值+6px圆角条+名称）；
  - 左下 foot：短横线 + 11.5px 字距标注。
- 浅色主题变量：底 #fafafa，fg #09090b，muted #52525b，边框 #e4e4e7，条形 fill #18181b / track #f4f4f5。
- 交付：按命名规则出 PNG（如 `YYYY.MM.DD_标题_2.3比例封面.png`、`YYYY.MM.DD_标题_方版1x1.png`），保留源 HTML。
- 截图踩坑：clip 超出视口需 `fullPage:true`，坐标用 `getBoundingClientRect + scrollY` 换算。

## 三、交付清单（每篇文章标配）
1. 正文 HTML：`日期_标题.html`（公众号适配版，全内联样式）
2. 封面 PNG ×2：`日期_标题_2.3比例封面.png` + `日期_标题_方版1x1.png`

## 风格 C：号外（EXTRA · 2026.10.26 新增 · 社会热点专用）

参考基线：`00-模板/号外/正文.html`（正文模板）+ `00-模板/号外/封面.html`（封面模板，含预览图）。

### 设计逻辑
社会热点稿的核心诉求：**快、观点前置、事实与观点分离、可引用**。报纸号外的视觉语言天然匹配——新闻纸底、黑粗标题、红章点睛。

### 配色（识别特征）
- 新闻纸米白 `#f7f4ec`（正文底）/ 米灰 `#efeadb`（引语/对照卡）
- 纯黑 `#1a1a1a`（标题/边框/结构）、次级 `#2b2b2b`、辅助 `#6b6552`
- **号外红 `#c9342b`**：仅用于编辑部观点徽章、关键事实/态度词、引语竖线——全文红色 ≤5 处
- 与锌白（黑白灰无红）、羊皮卷（米金深蓝）互斥不撞型

### 正文结构（强制顺序）
1. **报头**：黑边框底 + 左红章「号外 EXTRA」右期号 + 特粗宋体大标题 + 上下双细线关键词行
2. **导语**：加粗报纸腔 2-3 句（发生了什么+为什么值得聊）
3. **快评 · 一/二/三**：黑底白字章节徽章 + 特粗宋体标题；段落短句推进
4. 引语卡（红竖线 + 出处行）、**编辑部观点卡**（黑框 + 红徽章 + 一句钉子话）、立场对照卡（支持方▸/质疑方▸）
5. **后续盯什么 WATCHLIST**：黑底反白跟踪清单（01/02/03，写清判断标准）——本风格灵魂组件
6. 互动（"赞最高的下期单独写"）+ `— 号外完 · EXTRA —` 双细线报尾 + 口径说明（"本栏目不站队、只拆事"）

### 写作纪律
- 标题一句到位不绕弯；导语信息密度拉满无铺垫
- 每段只做一件事：陈述/举例/下判断
- 编辑部观点必须有一句可引用的钉子话；不站队，只拆事

### 封面（cover-号外.html 两画板）
- 2.3 报头版：米白报纸分栏底纹 + 顶部粗黑线 + 红色旋转「号外」章 + 黑宋体大标题（热点六字，可红字点睛）+ 双细线日期/关键词行
- 方版：同语言竖排 + 左下黑底「本期看点」卡（事件/争议/观点三行）+ 右下红色大号期号数字
- 生成参数化时可参照 `羊皮卷/gen_封面.py` 的思路，把标题/副题/期号/关键词做成参数

### 选型直觉
社会热点/争议快评/事件跟进 → 号外；科技数据清单 → 锌白；叙事历史游戏 → 羊皮卷。

## 风格 D：檄文（XI WEN · 2026.10.28 新增 · 讨伐体热点吐槽）

参考基线：`00-模板/檄文/正文.html`（正文模板）+ `00-模板/檄文/封面.html`（封面模板，含预览图）。
注：曾返工为 RPG 深黑游戏战报版，2026.10.28 经用户确认**回滚宣纸古文版**为正式定稿。

### 设计逻辑
把热点吐槽写成古文讨伐檄：**仿古战斗腔 × 现代破事**的反差制造诙谐，浓墨大字 + 朱砂印章制造视觉冲击。骂的是事，乐的是读者。

### 配色（识别特征）
- 暖宣纸底 `#f5edd8`（正文）/ 米黄卡 `#efe5c9`（罪状卡）/ 纸纹横线肌理
- 浓墨 `#141210`（标题/边框/黑底卡，比号外的 #1a1a1a 更暖更重）
- **朱砂 `#b53225`**（印章/罪状名/朱批/判词框）——比号外红更深更沉，带印泥感
- 竖排超大「檄」字水印（5% 透明度）贯穿全篇，是檄文独有的视觉签名
- 与羊皮卷（米金雅致）、号外（冷新闻纸）互斥：檄文是暖宣纸+墨+朱砂的"武"系

### 正文结构（强制顺序）
1. **檄首**：双粗边框 + 左红章「奉热榜之名」+ 右期号「讨伐檄 · 第 N 号」+ 大标题《讨「XX」檄》+ 仿古副题 + 右侧旋转朱砂「檄」大印
2. **起檄**：仿古开场段（盖闻……是可忍孰不可忍……鸣鼓而攻之），信息量照给
3. **檄曰 · 数罪**：罪状卡 ×3（罪名红字 + 事实陈述 + 旋转朱批印章），罪状递进：行为→态度→格局；朱批词库：离谱！/该！/岂有此理！/吃相难看！/呵呵，每篇 2-4 处
4. **檄曰金句卡**：黑底白字仿古狠句 + 右下「传阅」印
5. **判词 · 主判官**：朱砂粗框「本官判曰」钉子话——一半古腔一半人话；吐槽是壳，判断是核
6. **传檄天下**：黑底追踪清单（其一/其二/其三）
7. 互动（"赞最高者，下期补一张讨伐檄"）+ `— 檄文传阅 · 天下共讨 —` 报尾 + 口径（骂事不骂人，请勿对号入座）

### 写作纪律
- 罪状必须基于公开事实，吐槽靠腔调不靠编造；骂事不骂人，不对线
- 仿古腔浓度控制在"看得懂"边界内：起檄、檄曰用腔，判词必须落回人话
- 朱批是节奏器，不能滥盖

### 封面（cover-檄文.html 两画板）
- 2.3：宣纸纹 + 竖排「檄」水印 + 红章「奉热榜之名 · 讨伐檄」+ 旋转朱印 + 大字《讨「XX」檄》（XX 红字）+ 底部三枚罪状标签
- 方版：加黑底「檄曰」金句卡 + 「传阅」气泡印 + 底部期号日期行
- 参数化建议：title_main/对象名/副题/罪名×3/檄曰金句/期号

## 风格 E：Nvidia（GPU BRIEF · 2026.11.15 新增 · 科技公司快讯专用）

参考基线：`00-模板/Nvidia/正文.html`（正文模板）+ `00-模板/Nvidia/封面.html`（封面静态示例）+ `00-模板/Nvidia/gen_封面.py`（参数化生成器，输出双画板）。风格卡：`00-系统/styles/Nvidia.md`。实例见 `2026.11.15_黄仁勋辞任与员工公开信/正文.html`。

### 设计逻辑
快讯的核心诉求是**把事实和主张分栏摆出来**，让读者一眼分清"公司说的"和"有人要求的"。借 NVIDIA 品牌视觉（深绿黑 + 荧光绿 + 等宽终端 + GPU die 点阵）做识别，但正文底保持浅色，保证公众号可读性。

### 配色（识别特征）
- 页底 `#f7f9f3`（极浅绿白）/ 白卡 `#ffffff` / 浅卡 `#f1f6e9` / 边框 `#dfe8d2`
- 深绿黑 `#0d1509`（头部卡、数据卡、WATCHLIST），深卡内文字 `#eaf3dd` / `#d6e4c4` / 次级 `#9fb08a`
- **品牌绿 `#76b900`**：仅用于眉标、章节编号、左竖线、深卡内标题字
- **正文内绿字用 `#4c7a00`**（`#76b900` 在浅底上对比度不足，禁止直接当正文强调色）；亮绿 `#a6e22e` 仅用于深卡内数字
- 唯一强调色，不用第二种彩色；与锌白（无彩色）、号外（红）、檄文（朱砂）互斥

### 正文结构（强制顺序）
1. **头部深卡**：绿药丸「FLASH · 快讯」+ 右时间戳（Consolas）+ 24px 白标题 + 灰绿副题 + 绿细线 `▦ NVIDIA BRIEF // DISPATCH NNN // FACTS ≠ CLAIMS`
2. **导语**：加粗两句，直接点明"哪些是公告、哪些是单方主张"
3. `// 01 CONFIRMED · 已确认`：白卡 + 绿左竖线 + `NN ▸` 条目，句末带出处；下方等宽 `$ source:` 行
4. **数据卡**（深底三格）：数字用 Consolas，配 `$` 命令行式口径注
5. `// 02 CLAIMS · 单方主张`：浅绿卡列三条诉求 + 白卡写核心论点与"未获背书"声明
6. `// 03 TWO SIDES · 口径对照`：官方 ▸ / 公开信 ▸ 并置，明确哪一方具备确认效力
7. **WATCHLIST 深卡**：01/02/03，写清时间或判断标准
8. 口径说明卡（浅绿）+ 居中 `— 快讯完 · FLASH —`

### 写作纪律（本风格灵魂）
- **事实 ≠ 主张**：公司公告、监管文件、媒体转述、网站自报数据四个层级必须分别标注，不得混写
- 单方主张一律写「要求 / 认为 / 自述」，禁止写成陈述事实
- 涉及个人事项、国安/出口管制类指控：不转述、不评价、不展开，只在口径说明写"以公司公告与有权机关认定为准"
- 不站队、不作道德判断、不构成投资建议
- 短句、高密度、不铺垫；章节编号统一 `// NN KEYWORD · 中文`

### 封面（Nvidia/gen_封面.py 两画板）
- 深绿黑底 + 44px 绿网格 + 右上 GPU die 10×10 点阵（部分点亮）+ 径向绿光晕
- 2.3 版（900×383）：左 kicker「FLASH / 快讯」+ 期号 → 42px 白标题（关键词亮绿）→ 副题；右侧 290px 终端卡（三圆点栏 + `$ query --status` + 三行 metric）；底部日期/关键词行
- 方版（900×900）：54px 标题 + 全宽终端卡 + 左下「本期看点」卡 + 右下大期号 + 底部 `GPU BRIEF · FACTS ≠ CLAIMS`
- 参数：title_main/title_hl/sub/kw1-3/date/flash/m1-3_label+value/p_event/p_conflict/p_view/out
- 生成：`python 00-模板/Nvidia/gen_封面.py cfg.json`；不带参数则输出示例 `Nvidia/封面.html`

### 推送映射
言序主题选 **terminal（终端矩阵）**，与绿黑终端感最接近；黑绿卡片会由主题统一渲染，结构化块用 `paragraph / image / list / table`。

### 述评变体（warm_variant · 2026.11.15 新增）
用户反馈「快讯版冰冷、AI 味儿、没读下去的欲望」后补的第二形态。**配色与封面不变，只换正文骨架与笔法**，用于需要明确站队、有温度的题材（人物、不平事、公司治理述评）：

- 去掉 `// NN CONFIRMED` 机器编号、三格数据卡、表格、`$ source:` 命令行式注脚
- 章节标题改中文序数 + 18px 粗黑 + 下方 34px 绿短线；段落长短交错，允许单句成段
- 引语卡用宋体 `'STSong','SimSun',serif` 15.5px，与黑体正文形成温度差；金句卡深绿黑底 + 宋体大字
- 头部眉标可换「述评 · OPINION」，副标直接写清立场（如「不装中立」）
- 数字只出现一次、做大字，不铺数据卡
- 开篇用一条真实引语或一个具体场景起手，不用「某月某日公司公告」开场
- **可以站队、可以第一人称、可以下判断**，但事实仍须标出处；观点与事实在同一篇里仍要能分辨
- 口径说明必须加一句「本文是立场文，不伪装中立」，并写清哪些是单方主张、哪些是未证实的框架
- 封面生成器已参数化：`kicker` / `desk` / `foot_sig` 可替换快讯文案；2.3 版副标题限宽 490px，超过会压到右侧终端卡（踩过坑）

实例：`2026.11.15_黄仁勋辞任与员工公开信/正文.html`（述评版），对照同文件夹 git 历史的快讯版。
